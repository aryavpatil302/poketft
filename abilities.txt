PokéTFT: Full Ability Implementation Plan
Context
The user has a Pokemon TFT simulator with 8 Jungle abilities already implemented. The goal is to implement all ~45 remaining abilities from the design PowerPoint across 9 more traits (Beachy, Volcanic, Sky Striker, Cave Crawler, River, Temporal Woods, Ruiner, Ascender, Froststone) plus misc units — using clean, modular, reusable code.

Additionally, an HTML architecture diagram page (public/architecture.html) should be created showing combat flow and ability system structure.

1F. Add src/core/systems/heal.ts (new file)
Centralizes all healing so healBlock is respected everywhere:

export function applyHeal(unit: Unit, amount: number, sourceId: string, state: CombatState): number {
  const healBlock = unit.statusEffects.find(fx => fx.id === 'healBlock')
  const effective = healBlock ? Math.round(amount * (1 - (healBlock.magnitude ?? 0.33))) : amount
  const actual = Math.min(effective, unit.maxHp - unit.currentHp)
  unit.currentHp += actual
  if (actual > 0) state.events.push({ type: 'heal', targetId: unit.id, amount: actual, sourceId })
  return actual
}

Phase 2: Ability Implementations
One file per unit in src/core/abilities/. Register each handler in src/core/systems/ability.ts.

Standardized Status Effect IDs
ID	What it does	Key field
'burn'	periodic true dmg (tickEffect)	magnitude = dmg/tick, tickInterval = 60
'poison'	stackable periodic magic dmg	magnitude = dmg/tick, unique stackId per cast
'blind'	auto-attack miss chance	magnitude = miss probability (0.8 = 80%)
'chill'	attack speed slow	magnitude = slow fraction (0.3 = 30%)
'taunt'	force target override	sourceUnitId = taunting unit's id
'sunder'	flat armor reduction	magnitude = armor removed
'shred'	flat spDef reduction	magnitude = spDef removed
'healBlock'	reduce healing received	magnitude = fraction blocked (0.33)
'charm'	reduce attack+special	magnitude = fraction reduced
'confuse'	self-dmg on auto	magnitude = fraction of attack as self-dmg
'silence'	blocks ability casting	no magnitude
'atk_reduction'	flat attack debuff	magnitude = flat reduction
'atk_buff_pct'	% attack buff	magnitude = fraction bonus
'damageTakenMult'	amplifies incoming dmg	magnitude = added multiplier
